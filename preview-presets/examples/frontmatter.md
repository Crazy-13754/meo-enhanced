# Frontmatter / Properties

在 MEO 的 Preview 中依次选择 Typora Whitey、Obsidian Minimal 和 Typora Newsprint，查看同一份 frontmatter 的不同呈现。Whitey 与 Minimal 支持浅色和深色；Newsprint 仅支持浅色。

Switch between Typora Whitey, Obsidian Minimal, and Typora Newsprint in MEO Preview to compare the same frontmatter. Whitey and Minimal support light and dark themes; Newsprint supports light only.

## 分隔线与换行 / Dividers and wrapping

- Properties 标题与第一条属性之间有细横线。A fine rule separates the heading from the first property.
- 相邻顶层属性之间有横线。Horizontal rules separate top-level properties.
- `summary` 的多行内容保持为同一组，内部不加线。The multiline summary stays together without internal rules.
- 缩窄预览面板时，标签和值正常换行。Tags and values wrap when the preview panel narrows.

## 风格对照 / Style comparison

Whitey 的属性区融入纸面，Minimal 使用淡底圆角卡片，Newsprint 使用暖灰直角属性区。这些是基于 MEO Properties 的风格适配。

Whitey's property area blends into the paper, Minimal uses a subtly filled rounded card, and Newsprint uses a warm gray square panel. These styles adapt MEO Properties to each reading preset.
